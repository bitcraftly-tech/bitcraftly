# Versioning Strategy

Bitcraftly Platform follows Semantic Versioning.

```text
MAJOR.MINOR.PATCH

Example:

2.0.0

Major → Breaking Changes

Minor → New Features

Patch → Bug Fixes
```

---

# Release Process

Before every release:

- Update version number.
- Update CHANGELOG.md.
- Run all Quality Gates.
- Update documentation.
- Create Git tag.
- Publish release notes.

---

# Quality Checklist

Before publishing a release:

- Build passes
- TypeScript passes
- ESLint passes
- Documentation updated
- Accessibility verified
- Performance verified
- Security reviewed
