## Purpose

This directory captures **why** the platform is built the way it is. Use it when:

- Onboarding engineers who need context on structural decisions
- Evaluating proposals that would change core architecture
- Recording trade-offs for future reference

## ADR format

Architecture Decision Records follow this naming convention:

```
ADR-NNN-short-title.md
```

Each ADR should include: **Status**, **Context**, **Decision**, **Consequences**, and **Alternatives Considered**.
