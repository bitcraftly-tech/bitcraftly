# Reviews

Audit reports, foundation reviews, and technical assessment documents for the Bitcraftly Platform.

## Purpose

This directory archives formal reviews that evaluate the health, structure, and readiness of the codebase. Reviews provide a point-in-time snapshot and actionable recommendations.

## Contents

| Document | Description |
|----------|-------------|
| [PROJECT_FOUNDATION_REVIEW.md](../../PROJECT_FOUNDATION_REVIEW.md) | Initial Principal Frontend Architect audit (2026-07-11) |

## When to add a review

- After major architectural changes or migrations
- Before production launch or significant releases
- During periodic codebase health checks
- After security or performance audits

## Review format

Each review should include:

1. **Scope** — What was evaluated
2. **Findings** — Issues categorized by severity
3. **Recommendations** — Prioritized action items
4. **Status** — Open, in progress, or resolved follow-ups

## Naming convention

```
REVIEW-TYPE-YYYY-MM-DD.md
foundation-review-YYYY-MM.md
security-audit-YYYY-MM.md
```
