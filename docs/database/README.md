# Database

Schema definitions, migrations, and data model documentation for Bitcraftly Platform V2.

## Stack

- **ORM:** Prisma 7
- **Database:** PostgreSQL (Neon recommended)
- **Client output:** `src/generated/prisma/` (gitignored — generated by `npm run db:generate`)

## Commands

| Command               | Environment        | Description                                                        |
| --------------------- | ------------------ | ------------------------------------------------------------------ |
| `npm run db:generate` | All                | Generate Prisma client (runs automatically before `npm run build`) |
| `npm run db:migrate`  | **Local dev only** | Create and apply migrations (`prisma migrate dev`)                 |
| `npm run db:deploy`   | **Production**     | Apply pending migrations (`prisma migrate deploy`)                 |
| `npm run db:push`     | Local prototyping  | Push schema without migration files                                |
| `npm run db:studio`   | Local dev          | Prisma Studio GUI                                                  |

## Production migrations

Use the GitHub **Database Migrate Deploy** workflow or run manually:

```bash
DATABASE_URL="..." DIRECT_URL="..." npm run db:deploy
```

Never run `db:migrate` against production.

See [Production Deployment Guide](../engineering/production-deployment.md) for the full workflow.
